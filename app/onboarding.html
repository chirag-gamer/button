What button does

One click gets your screen recording-ready: it starts Do Not Disturb, hides your desktop icons and other windows, keeps the screen awake, and puts everything back afterwards.

Alt+R does the same from anywhere, without opening the tray menu.

Recording Mode hotkey

Press this anywhere to start and stop recording mode.

Alt+R

Press the new shortcut, Esc to cancel.

Some apps use Alt+R themselves. If it clashes, pick something else here.

Where the tray icon is

Windows may hide button's icon in the taskbar overflow.

Click the ^ "Show hidden icons" arrow next to the clock: button is in that flyout.

To keep it on the taskbar, drag button out of the flyout onto the taskbar. Or open Settings › Personalization › Taskbar › Other system tray settings and turn button on.

Open Settings › Personalization › Taskbar › Select which icons appear on the taskbar and turn button on.

Left-click the icon to open the panel, right-click for the tray menu.

Start with Windows

button needs to be running for the hotkey and the tray icon to work, so starting it with Windows is recommended.
